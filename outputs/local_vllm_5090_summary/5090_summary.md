# Every result measured on the lab RTX 5090

Generated by `scripts/local_vllm/report_5090_runs.py` from the run folders. No figure is typed by hand.

## How to read this

* **Invalid rate** is the share of the keywords a model selected that do not exist in the course catalogue. Lower is better.
* **All queries** counts a query the model failed to answer as a complete failure (rate 1.0). **Answered queries** leaves those out.
* **Silent runs** are runs where the model produced no usable keyword, so nothing was retrieved.
* Every cell is the full pipeline on 50 learner queries. Passes are averaged per query before any interval or test, so n is queries, not runs.
* Local cells are **not pooled** with hosted ones. The hosted rows in Section 5 are for orientation only.
* The model served at 70B size does not fit this card (32 GB), so there is no local 70B cell.
